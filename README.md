# Проектная работа 8 спринта

## Задание
Докрутить в имеющийся фронт PKCE, добавить бэкэнд с авторизацией и проверкой подпсии/ролей по адресу `/reports`.

## Что сделано

- В реалме добавлен атрибут для поддержки PKCE;
- В [`/frontend/src/App.tsx`](./frontend/src/App.tsx) прописана инициализация провайдера с PKCE;
- В [`/api](./api) добавлен .NET9 проект с эндпоинтом `/reports`;
- В api настроена проверка токенов с реалма, в том числе подпись издателя и наличие роли `prothetic_user` (через политику авторизации);
- API отдает объект с Id/Именем юзера и сотней рандомных значений миодатчиков. Без токена возвращает 401, без роли - 403;
- Вебморда при успешном запросе показывает json с данными.

## Запуск

```bash
# По какой-то причине  просто compose up работает только в IDE - в терминале виснет на этапе восстановления зависимостей. 
# В качестве костыля билдим образ отдельно и запускаем композ с готовым.
docker build --network=host -t bionicpro-api -f api/Dockerfile . --no-cache && docker compose up
```
